# Verdetto

Verdetto is a free QR code and barcode scanner for Android with no ads and no fake buttons. It shows the link before it opens, is built to read damaged codes, and checks scanned content for warning signs on the phone. It never says anything is safe: "No warnings found" means none of its checks matched.

**Status:** closed test soon, then Google Play. Want to test it before release? Write to support@verdettoqr.com.

## What is here

- [link-safety-list](https://github.com/verdettoqr/link-safety-list): the phishing and scam list the app checks on the phone, compiled in the open from public feeds four times a day and signed. Read the sources, the rules, and every release.
- [verdettoqr.com](https://github.com/verdettoqr/verdettoqr.com): the website, a static build with no trackers. Corrections welcome as pull requests.
- The app's source is published with its first release.

## Reporting a problem

A code that would not read, a warning that felt wrong or missing, or a list entry that should not be there: open an issue on the repository it concerns, or write to support@verdettoqr.com. Security reports go to the same address; please do not open a public issue for those.
