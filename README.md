# Verdetto

**QR & Barcode Scanner for Android.** No ads, no fake buttons. See the link before it opens. Reads damaged codes.

Verdetto shows you what a code contains before anything opens, checks it for warning signs on the phone, and compares links, sites, and wallet addresses with a list of known phishing and scam entries kept on the device. It never says anything is safe: "No warnings found" means none of its checks matched, and the decision is always yours.
